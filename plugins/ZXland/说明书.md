# ZXland 领地系统
## 功能特性

- **领地创建** - 木斧选点，支持2D/3D领地
- **权限管理** - 精细化权限控制，支持自定义权限组
- **成员系统** - 邀请、申请加入、成员权限分级
- **领地保护** - 防爆炸、防火焰、防活塞、防液体等全方位保护
- **传送系统** - 领地传送、自定义传送点
- **子领地** - 支持在主领地内划分子领地
- **领地飞行** - 主人可在领地内开启飞行
- **黑名单** - 禁止特定玩家进入
- **经济系统** - 领地购买、税收、退款
- **可视化** - 粒子边界显示

## 命令大全

### 基础命令

领地管理员需要再控制台输入 zxland op add 玩家名
zxland op remove <玩家名>移除领地管理员
zxland op list查看管理员列表
| 命令 | 说明 |
|------|------|
| `/land` | 打开领地主菜单 |
| `/land help` | 查看帮助信息 |

### 选区命令
| 命令 | 说明 |
|------|------|
| `/land new` | 开始创建新领地 |
| `/land pos1` | 设置选区点1（当前脚下） |
| `/land pos2` | 设置选区点2（当前脚下） |
| `/land set` | 循环设置选区点 |
| `/land giveup` | 放弃当前选区 |
| `/land cancel` | 同上，取消选区 |
| `/land buy` | 购买当前选区领地 |
| `/land create` | 同上，创建领地 |
| `/land ok` | 确认重选领地范围 |
| `/land confirm` | 同上，确认操作 |

## API 接口

本插件开放 **78个** API接口供其他插件调用：

```javascript
// 导入示例
let getLandAt = ll.imports("ZXland", "getLandAt");
let hasPermission = ll.imports("ZXland", "hasPermission");
```

### 主要接口

| 接口 | 说明 |
|------|------|
| `getLandAt` | 获取坐标所在领地 |
| `getLandInfo` | 获取领地完整信息 |
| `hasPermission` | 检查玩家权限 |
| `createLand` | 创建领地 |
| `deleteLand` | 删除领地 |
| `addMember` | 添加成员 |
| `removeMember` | 移除成员 |
| `isOwner` | 检查是否为主人 |
| `isMember` | 检查是否为成员 |
| `teleportPlayer` | 传送到领地 |
| `setProtection` | 设置保护选项 |
| `enableFlight` | 启用领地飞行 |
| `visualizeLand` | 显示领地边界 |

完整API文档见 `API.md`

## 配置

首次运行自动生成 `config.json`，可自定义：
- 领地价格、税率
- 最大领地数量、成员上限
- 默认权限设置
- 界面颜色样式

## 安装

1. 将 `ZXland.js` 放入 `plugins/ZXland/` 目录
2. 重启服务器
3. 输入 `/land` 开始使用
